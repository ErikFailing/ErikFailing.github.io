# Security policy

If you find a security issue with erikfailing.com or this repository, please report it privately
through GitHub: **[Report a vulnerability](https://github.com/ErikFailing/ErikFailing.github.io/security/advisories/new)**
(also under this repo's **Security** tab).

Please don't open a public issue for security problems.

**In scope:** this site and the code in this repository, such as the Hugo configuration, templates,
and the GitHub Actions workflow.

**Out of scope:** GitHub Pages itself, and the PaperMod theme (report those to
[GitHub](https://bounty.github.com/) and [PaperMod](https://github.com/adityatelange/hugo-PaperMod)).

This is a personal site with no bug bounty, but I appreciate reports and will credit you if you
like.
